## 📖 平台簡介

本專案為王玉珍老師「放數學一馬－AI 攜手成為千里馬的伯樂」Padlet 研習看板的完整互動數位典藏版。具備離線資源自給自足、高解析度桌布布景、全卡片分類色彩標籤、一鍵提示詞複製、即時關鍵字搜尋與燈箱瀏覽等強大功能，並配置磨砂玻璃門禁密碼保護系統。

### 🏷️ 貼文分類顏色系統
- 🔴 **紅色**：平台與功能說明（學習扶助科技化評量平台、基本學習內容脈絡）
- 🟡 **黃色**：AI 協作提示詞（各年級篩測結果運用、學校整體概況、診斷學習卡點、共備議題規劃、二級編班分析、縱貫性簡報提示詞）
- 🟢 **綠色**：重點說明與承辦人角色（一定要有的資料、建議補充資料、資料去個資處理原則）
- 🔵 **藍色**：必須提供給 AI 的資料（數學領綱、數學學習內容解析）
- ⚪ **灰色/預設**：各年級基本學習內容教材（一至六年級）、因材網等數位平台
